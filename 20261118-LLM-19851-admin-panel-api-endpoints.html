Admin Panel: which APIs let a site admin edit a provider's template

Parent: LLM-19851 · FE PR: scribe-mobile#6539 · Updated 2026-11-18

API What it does Supports admin editing a provider? Needs BE change?
GET /custom_formatting/format_option_settings/{templateId}Load provider's formatting settingsYesNo
POST /custom_formatting/format_option_settingsSave a formatting changeYesNo
DELETE /custom_formatting/format_option_settings/{templateId}/{customFormatId}/{section} Clear a formatting setting No, acts on the admin's own account. It can delete the admin's own setting. Yes, LLM-21928 (small). Disabled in admin mode for now.
POST /template_builder/edit_template_v2 (template builder) Add, remove, or rename subsections and rename the template No, returns 403 because the admin isn't the template's owner. Nothing is saved. Yes, LLM-21929 (medium, needs product sign-off). Locked in admin mode for now.
GET /templates/section_generationLoad provider's subsectionsYesNo
POST /templates/section_generationCreate a subsection rowYesNo
PATCH /templates/section_generation/{id}Turn a subsection on or offYesNo
POST /templates/section_generation/reorderReorder subsectionsYesNo
GET /macros/macros_by_sectionLoad provider's macrosYesNo
GET /macros/macro_links_by_templateLoad macro-to-template linksYesNo
POST /macros/create_and_link_macroAdd a macroYesNo
PATCH /macros/{macroId}Edit a macroYesNo
PATCH /macros/macro_link/{linkId}Edit a macro link or toggle it on or offYesNo
POST /macros/copy_and_relink_macroCopy and relink a macroYesNo
DELETE /macros/macro_template_account/{linkId}Remove a macroYesNo

Not used by the admin screen, so out of scope: GET /custom_formatting/format_option_settings/{templateId}/{customFormatId}/{section} (fetch one setting) and deleting a macro outright. Both also ignore the provider.
