Scribe prod error: TypeError: can only join an iterable

Cloud Run service scribe-prod, route POST /generate_workflow_task_output, 2026-10-01 14:36:59 UTC.

Root cause

GenerateWorkflowTaskOutput.transcriptions is declared Optional[list[str]] = None (errands/jobs/openai/schemas.py). For a request that supplies documents but no transcript (no transcriptions, no diarized_transcriptions, is_pre_chart=False), the controller's 422 validation does not reject it, so None reaches macro_llm_call, which does: 

"transcription": " ".join(transcriptions) + ...

" ".join(None) raises the TypeError.

Call path

generate_workflow_task_output (controllers.py:~3571)
  → get_selected_macros (services.py:1534)
    → select_and_fill_macros (services.py:660)   # transcriptions param, no None-guard
      → macro_llm_call (services.py:860)          # " ".join(transcriptions) crashes

Fix

errands/jobs/macros/services.py — normalize at the top of select_and_fill_macros, which feeds both call sites into macro_llm_call:

transcriptions = transcriptions or []

Also widened the parameter type hint from List[str] to Optional[List[str]] to match what it actually receives.
